# Create: Creative Tools Fabrication

### A simple mod that lets you keep your Create tools when clearing your inventory in Create

# Create: Factory Tweaks

### Adds compatibility with TFMG and the straw Blaze Burner from Create Crafts & Additions and has modifiable configs

Also adds a slightly adjusted distillation preset for oil distillation. Everything is adjustable with a config screen.

# Create: TFMG Aviation

# Create: Trains Interactive

### Lets you use storage, furniture, bar and kitchen blocks on Create trains

Supports Kaleidoscope Tavern, World Liquor and Farmer's Delight, including Pick Block on moving trains.
